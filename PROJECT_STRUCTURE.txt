核心功能:
1. prep-system.sh
   - 禁用 SELinux 和防火墙
   - 配置内核参数和系统优化
   - 禁用 swap
   - 配置时间同步
   - 设置主机名和 hosts
   - 配置 IPVS 模块
   - 严格的错误处理和日志记录

2. install-docker-k8s.sh
   - 支持 Docker 和 containerd 两种运行时
   - 安装 kubeadm, kubelet, kubectl
   - 配置 cgroup 驱动
   - 支持镜像加速器（阿里云）
   - 预拉取 Kubernetes 镜像
   - 完整的安装验证

3. init-master.sh
   - 初始化 Kubernetes Master 节点
   - 支持 Calico 和 Flannel 网络插件
   - 自动生成 kubeadm 配置
   - 配置 kubectl 访问
   - 生成 Worker 加入命令
   - 支持 HA（高可用）模式
   - 集群状态验证

4. join-worker.sh
   - Worker 节点加入集群
   - 支持 SSH 自动获取加入信息
   - 支持交互式和非交互式模式
   - 配置节点标签
   - 完整的加入状态验证

使用示例:
# 快速部署单 Master 集群
1. 所有节点: sudo ./prep-system.sh
2. 所有节点: sudo ./install-docker-k8s.sh --runtime containerd --use-mirror
3. Master: sudo ./init-master.sh --network-plugin calico
4. Worker: sudo ./join-worker.sh --master-ssh root@<master-ip>
